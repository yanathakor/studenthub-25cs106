# About the Project

StudentHub is a centralized web portal developed to simplify students' access to academic and campus-related services. Instead of navigating multiple systems, students can manage important academic information from a single platform.

This project serves as the foundation for a semester-long Web Technology project.

---

# Objectives

- Create a centralized student portal.
- Simplify access to academic information.
- Improve user experience through intuitive navigation.
- Build a scalable project for future enhancements.
- Apply Web Technology concepts in a real-world application.

---

# User Roles

## Student

- Secure Login
- View Dashboard
- Check Attendance
- View Assignments
- Download Hall Ticket
- Check Holidays
- Explore Events
- Submit Suggestions
- Access Lost & Found

## Administrator (Future Scope)

- Manage Students
- Manage Events
- Publish Holidays
- Update Assignments
- Generate Reports
